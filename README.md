# Family Tree Maker

A local, dependency-free family tree editor inspired by the broad workflow of Family Echo. It runs entirely in your browser and stores your tree in local storage.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## Features

- Add parents, partners, children, and siblings
- Edit personal details, life events, contact information, notes, and photo URLs
- Search people and refocus the tree by double-clicking a person
- Zoom, compact/full tree depth, and print layout
- Local autosave
- Export/import JSON
- Basic GEDCOM import for people, families, names, birth/death dates, places, and notes

This is a clean local implementation, not a copy of Family Echo source code or branding.
